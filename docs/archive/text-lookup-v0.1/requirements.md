> 归档：当前产品行为已合并到 `../../product-design-v0.1.md`。

> 状态：Archived（首版产品合同快照）
> 日期：2026-08-14
> 适用范围：Text Lookup Plugin v0.1
> 文档职责：定义鼠标划词、鼠标指针取词、释义、原句翻译和闪卡创建的用户行为、范围与验收标准。工程边界与实现顺序见《zbox 鼠标取词插件设计方案 v0.1》。

## 1. 产品定义

Text Lookup Plugin 是随 zbox 静态编译、可由用户启停的第一方原生插件。它让用户在其它 macOS 应用中划选单词或短语，或者通过快捷键查询鼠标指针下的单词，并在就近出现的悬浮窗口中查看：

- FlashDict 主词典释义；
- 单词或短语所在原句；
- 原句的 Apple 本地翻译；
- 基于所选义项和原句创建 FlashDict 闪卡的操作。

首版不建设动态插件 Runtime、第三方插件 SDK 或插件市场。插件身份用于建立清晰的启停生命周期、功能边界和设置归属，而不是承诺外部插件兼容性。

## 2. 已确认的产品决策

| ID | 决策 |

| TLP-DEC-003 | “光标取词”中的光标指鼠标指针，不指文本插入光标。 |

| TLP-DEC-007 | Accessibility 失败时可启用默认关闭的剪贴板兼容取词。 |
| TLP-DEC-008 | 取不到原句时仍继续查词，并允许创建不带原句的闪卡。 |

| TLP-DEC-016 | 悬浮窗口出现时不主动抢走当前应用焦点。 |
| TLP-DEC-017 | 始终忽略安全输入框，并支持按应用排除取词。 |

## 3. 术语

- **划词**：用户在其它应用中通过鼠标拖动、双击等方式形成非空文本选区。
- **指针取词**：用户按下取词快捷键后，读取鼠标指针所在位置的单词。
- **选区候选**：划词结束后捕获并短期保留、尚未触发查词的文本上下文。
- **原句**：包含被查单词或短语的完整句子；无法可靠识别时为空。
- **兼容取词**：Accessibility 无法读取已有选区时，经用户启用后临时模拟复制来读取选区。
- **查词会话**：从一次有效触发开始，到悬浮窗口被替换或关闭为止的一组捕获、释义、翻译和建卡状态。
- **主词典**：FlashDict 当前配置的 primary dictionary。

## 4. 核心用户路径

### 4.1 划词后自动查询

```text
用户划选单词或短语
  → 插件读取选区、原句、来源和选区位置
  → 判断选区长度与应用排除规则
  → 就近显示悬浮窗口
  → 并行加载 FlashDict 释义与原句翻译
```

### 4.2 划词后快捷键确认

```text
用户划选单词或短语
  → 插件保存短期选区候选，不显示窗口
  → 用户在候选有效期内按取词快捷键
  → 使用该候选查询并显示悬浮窗口
```

### 4.3 鼠标指针取词

```text
当前没有有效选区候选
  → 用户按取词快捷键
  → 插件读取鼠标指针下的单词及所在句子
  → 就近显示悬浮窗口并开始释义与翻译
```

### 4.4 创建带原句闪卡

```text
FlashDict 释义完成
  → 用户选择一个义项并添加闪卡
  → 插件附加原句和可用的来源 URL
  → FlashDict 同步返回添加、额度拒绝或失败结果
```

## 5. 功能需求

### 5.1 插件生命周期

#### TLP-FR-001：启用与停用

- Settings 提供 Text Lookup Plugin 总开关。
- 插件默认关闭；只有 Accessibility 已授权时才能完成启用并注册所需鼠标监听、快捷键和取词状态。
- 用户尝试在未授权状态启用时，开关保持关闭并解释权限用途，由用户显式请求权限或打开系统设置。
- 停用后立即注销插件拥有的监听和快捷键、取消未完成任务并关闭悬浮窗口。
- 停用不删除用户设置或排除列表。
- zbox 重新启动后只在持久化设置为启用且 Accessibility 仍有效时恢复运行。
- 权限被撤销时插件自动关闭并写回停用状态，但保留其它设置；用户重新授权后再次打开总开关即可恢复，不自动启动。

### 5.2 划词触发

#### TLP-FR-002：触发模式

划词模式必须支持：

- **Automatic**：有效划词完成后自动显示悬浮窗口；
- **Shortcut Required**：划词后只保存短期候选，按取词快捷键后显示；
- **Off**：不因划词生成候选或显示窗口，仍允许快捷键执行指针取词。

默认模式为 Automatic。

#### TLP-FR-003：选区范围

- 单词和短语均按用户精确选区查询。
- 查询前移除首尾空白和无语义的外围标点，保留短语内部文本顺序。
- 首版自动触发上限为 80 个字符且不超过 8 个词；任一上限超出即不自动显示。
- 过长选区不得被擅自截断或改成查询其中某一个词。
- 空选区、纯空白选区和纯标点选区不得触发。

#### TLP-FR-004：候选优先级

- Shortcut Required 模式下，候选默认保留约 3 秒。
- 候选有效期内按取词快捷键时优先使用候选，不执行指针取词。
- 候选过期、目标应用变化或选区失效后，快捷键改为执行指针取词。
- 新候选替换旧候选。

### 5.3 快捷键与指针取词

#### TLP-FR-005：取词快捷键

- 首版允许用户从支持的组合键和双击修饰键预设中选择。
- 初始预设至少包含 `⌥C` 和双击 `⌥`。
- 首版不支持单按 `⌥`，也不建设任意键盘手势、tap/hold 或通用 chord 引擎。
- 快捷键必须参与 zbox 内部冲突检测；冲突或系统注册失败时不得悄悄覆盖原配置。

#### TLP-FR-006：鼠标指针取词

- 没有有效选区候选时，快捷键查询鼠标指针所在位置的单词。
- 指针落在空白、不可读内容、安全输入框或非文本元素上时显示明确失败反馈。
- 指针取词不得为了读取文字而改变目标应用选区。
- 指针取词不使用剪贴板兼容取词。

### 5.4 文本与上下文捕获

#### TLP-FR-007：捕获结果

一次成功捕获至少包含：

- 用于查询的单词或短语；
- 用于定位悬浮窗口的屏幕范围或鼠标位置。

能够取得时还应包含：

- 原句；
- 来源 URL；
- 来源应用 bundle identifier。

#### TLP-FR-008：原句识别

- 原句应是包含目标词或短语所在范围的句子，而不是任意相邻文本。
- 原句识别失败不影响释义查询。
- 原句缺失时翻译区域显示可理解的缺失状态，不发起空翻译请求。
- 插件不得伪造、拼接或根据网页标题猜测原句。

#### TLP-FR-009：来源 URL

- 对暴露 URL 的浏览器或文档应用尽力获取来源 URL。
- 获取失败时 `sourceURL` 为空，不阻断释义、翻译或建卡。
- 非 URL 来源不得用窗口标题或本地应用路径伪造成 URL。

### 5.5 Accessibility 与兼容取词

#### TLP-FR-010：权限引导

- 插件依赖 Accessibility 权限读取其它应用文本并监听所需全局事件。
- 未授权、被拒绝或授权被撤销时必须解释用途并提供进入系统设置的操作。
- 系统授权提示只能由用户显式启用插件或点击请求权限时触发；普通取词失败不得自动弹出授权提示。
- 权限恢复后插件无需重启；用户再次打开总开关即可重新尝试。
- 不要求 Screen Recording 权限。

#### TLP-FR-011：剪贴板兼容模式

- 兼容取词设置默认关闭，用户必须主动开启。
- 只在已存在文本选区且 Accessibility 读取失败时使用。
- 使用前尽力保存当前剪贴板，读取完成后仅在不会覆盖用户后续剪贴板变化时恢复。
- 兼容取词失败必须明确结束，不循环模拟复制。
- 指针取词、安全输入框和排除应用永远不进入兼容取词。

### 5.6 悬浮窗口

#### TLP-FR-012：显示与焦点

- 悬浮窗口优先锚定选区范围；没有可靠范围时锚定鼠标位置。
- 窗口应避开当前屏幕可用区域边缘，空间不足时在目标上方显示。
- 出现时不激活 zbox，不夺走目标应用键盘焦点，不清除原选区。
- 用户点击窗口后可以与释义、语言选择和建卡操作交互。
- Escape、点击窗口外部、触发新查词、停用插件或退出 zbox 时关闭窗口。
- 新查词使用同一窗口并替换旧会话；首版不同时保留多个查词窗口。

#### TLP-FR-013：信息层级

悬浮窗口从上到下展示：

1. 查询词或短语；
2. 原句；
3. 原句翻译状态或结果，以及目标语言快捷按钮；
4. FlashDict 主词典释义；
5. 当前义项的建卡状态或可操作错误。

释义与翻译独立加载、独立失败。任一部分失败不得清除另一部分的成功结果。

#### TLP-FR-014：通用状态

窗口必须覆盖：

- 正在捕获；
- 正在查词；
- 正在翻译；
- 查词成功；
- 无查词结果；
- 原句不可用；
- 翻译语言不支持或模型未安装；
- FlashDict 未运行；
- FlashDict 主词典不可用；
- Accessibility 权限缺失；
- 当前应用或文本元素不支持取词；
- 闪卡添加中、已添加、额度拒绝和添加失败。

### 5.7 FlashDict 释义

#### TLP-FR-015：本机查词

- 通过 `FlashDictIntegrationKit` 查询 FlashDict 主词典。
- zbox 不读取 MDX/MDD、不创建索引、不包含 MdictKit 或 extractor。
- 首版不查询 FlashDict 的其它词典，不聚合多个 LookupDocument。
- 新查词必须取消旧查词；旧响应不得覆盖当前窗口。

#### TLP-FR-016：FlashDict 未运行

- FlashDict 未运行时展示简短说明和“启动 FlashDict”按钮。
- 插件不得自动启动 FlashDict、后台轮询或自动重连。
- 用户点击启动后，由用户再次触发或点击明确的重试操作。

### 5.8 原句翻译

#### TLP-FR-017：Apple 本地翻译

- Apple Translation 是首版唯一可被选择并实际执行翻译的 provider。
- 翻译在设备端完成。
- 缺少语言模型时使用系统提供的下载授权和进度体验。
- 源语言默认自动识别。
- 目标语言默认使用 macOS 首选语言，用户可在 Settings 中固定指定。
- 当源语言与目标语言相同或语言组合不受支持时显示明确状态。

#### TLP-FR-018：目标语言快捷调整

- 翻译区域提供紧凑、可访问的目标语言按钮。
- 修改后只重新翻译当前原句，不重新执行文本捕获或词典查询。
- 快捷调整同时更新持久化目标语言设置，后续查词沿用新选择。

#### TLP-FR-019：第三方翻译边界

- 首版不定义通用第三方 provider 合同，不展示或持久化不可工作的 provider 配置。
- 首版不创建第三方翻译 Keychain 项，也不使用真实第三方账号、API Key 或网络请求。
- 第一个真实 provider 进入已排期的用户闭环后，再按其鉴权、DTO、错误与隐私要求增加窄实现边界。

### 5.9 创建闪卡

#### TLP-FR-020：义项建卡

- 使用 `FlashDictLookupSurface` 发出的冻结 `SenseSelection.cardSeed` 创建闪卡。
- 建卡上下文附加捕获到的原句和来源 URL。
- 原句翻译不写入闪卡，也不塞入 `userNote`。
- 每次用户明确点击添加都生成新的 delivery ID。
- 同一次失败不自动重试；用户再次点击表示新的添加动作。
- 添加结果映射为已添加、额度拒绝或失败，不显示虚假的排队状态。

### 5.10 排除与隐私

#### TLP-FR-021：安全输入和应用排除

- 密码、安全文本字段和系统明确标记为受保护的文本永远不读取。
- 默认排除 zbox 与 FlashDict 自身，避免递归触发。
- Settings 支持按应用增加、移除排除项。
- 被排除应用中的鼠标事件不得生成文本候选、查词或翻译请求。

#### TLP-FR-022：本地数据与日志

- 捕获的单词、原句和 URL 只保存在当前查词会话内，除非用户明确创建闪卡。
- 不建立取词历史、不上传捕获内容、不把原文写入普通 Release 日志。
- 非敏感设置使用 UserDefaults。

### 5.11 会话一致性

#### TLP-FR-023：取消和旧结果隔离

- 每次有效触发创建新的查词会话身份。
- 新会话取消旧文本捕获、释义和翻译任务。
- 被取消任务不得转成用户可见错误。
- 即使底层取消未及时生效，只有当前会话身份匹配的结果可以更新窗口。
- 停用插件和 zbox 退出时取消所有插件任务。

## 6. Settings 需求

Text Lookup 设置至少包含：

- 插件启用开关；
- 划词触发模式；
- 取词快捷键预设；
- 剪贴板兼容取词开关；
- 默认目标语言；
- 应用排除列表；
- Accessibility 授权状态、请求授权与打开系统设置；

设置文案至少提供简体中文与英文。权限、隐私和兼容模式文案必须说明实际行为，不使用“增强体验”等含糊描述。

## 7. 首版范围外

- 动态加载插件、第三方插件 SDK、插件签名协议或插件市场；
- FlashDict 多词典查询、并行查询或结果聚合；
- 剑桥、朗文、柯林斯及其它在线词典；
- Google、DeepL、LLM 等第三方翻译网络 adapter、通用 provider 合同、配置 UI 与凭据存储；
- 保存原句翻译到 FlashDict 闪卡；
- 文本插入光标取词；
- OCR、截图取词或 Screen Recording；
- 对过长段落自动摘要、翻译或猜测查询词；
- 单按 Option、tap/hold、Hyper Key 或通用键盘手势引擎；
- 固定悬浮窗口、多个并存窗口、查词历史；
- 对拒绝暴露 Accessibility 文本且无法复制的应用承诺兼容。

## 8. 验收标准

### 8.1 自动化验证

- 选区清洗、字符/词数上限和空输入判定；
- 选区候选有效期、替换、过期和优先级；
- 普通组合键冲突和双击修饰键识别；
- 原句边界识别和原句缺失行为；
- 新会话取消旧会话、旧结果不覆盖新窗口；
- 插件停用后监听、快捷键、任务和窗口均被清理；
- UserDefaults 设置恢复；
- FlashDict 查词、未运行、无结果和建卡结果映射；
- Apple 翻译加载、成功、不支持、取消和目标语言变更状态；
- 排除应用和安全输入框不会进入捕获或兼容取词；
- 悬浮窗口定位纯计算覆盖屏幕边缘与上下翻转。

### 8.2 手工应用矩阵

首版至少验证：

- Safari；
- Google Chrome；
- TextEdit；
- 备忘录；
- Xcode；
- Visual Studio Code 或另一款 Electron 应用；
- Preview 中的可选中文本 PDF。

每个应用至少覆盖划词自动触发、快捷键确认、鼠标指针取词、原句获取、窗口定位和失败反馈。终端、自绘文本控件和 Accessibility 实现不完整的应用只承诺尽力支持，并记录实际能力边界。

### 8.3 系统场景

- Accessibility 首次授权、拒绝、撤销与重新授权；
- 普通桌面、全屏应用、多个 Space；
- 单显示器和外接显示器；
- FlashDict 未运行、运行中退出、主词典不可用、查词无结果；
- Apple 翻译语言模型未安装、下载被取消、语言组合不支持；
- 剪贴板兼容取词启用和关闭；
- 快速连续对不同词触发查词。

## 9. 完成定义

Text Lookup Plugin v0.1 只有在以下条件同时满足时完成：

1. TLP-FR-001 至 TLP-FR-023 均已实现，或在范围文档中经 owner 明确移除；
2. 自动化验证通过；
3. 手工应用矩阵完成并记录每个应用的能力边界；
4. App Group、Developer ID 签名和跨进程 FlashDict 资源加载经过真实应用验证；
5. 悬浮窗口在普通桌面、全屏、Space 和多显示器下不抢焦点且位置可用；
6. 已知不支持场景均提供明确失败，不存在自动轮询、无限重试或旧结果覆盖新会话；
7. Release 日志和持久化设置中没有意外保存捕获原文或秘密凭据。
