# Calculator 产品约定

> 权威性：Normative Product Contract
> 加载方式：涉及 Calculator 入口、窗口、输入、运算或数值语义时读取
> 状态：Active
> 初始日期：2026-09-03
> 适用范围：Calculator 内置独立扩展 v0.1

## 1. 产品定位

Calculator 是随 zbox 静态编译的本地整数计算器。它通过核心 Command Registry 暴露入口，以独立原生窗口提供接近 macOS 计算器的按键体验，并让十进制与十六进制结果始终同时可见。

它不建立动态插件 Runtime、扩展 SDK、独立进程或网络依赖。Calculator 不需要权限、不在后台监听，也不需要启停设置。

## 2. 入口与窗口

- Root Search 中始终提供 `Calculator` Command；点击结果或按 Return 后隐藏 Root Search，并打开或聚焦 Calculator 窗口。
- Calculator 使用可关闭、最小化和调整大小的普通 macOS 窗口。关闭窗口不退出 zbox，再次执行 Command 可重新打开。
- 窗口同时显示 `DEC` 和 `HEX` 两行结果，并以分段控件明确当前输入进制。

## 3. 数值与运算语义

- v0.1 只处理 64 位有符号整数。
- 十六进制显示使用对应 64 位补码；例如十进制 `-1` 显示为 `FFFFFFFFFFFFFFFF`。
- 支持数字 `0–9`、十六进制数字 `A–F`、加、减、乘、整数除法、正负号、退格、全部清除和等号。
- 运算按普通按键计算器的即时执行方式从左到右求值，不解析带优先级的完整表达式。
- 十进制输入模式禁用 `A–F`；切换输入进制不改变当前数值，只改变后续数字的解释方式。
- 除零和 64 位溢出显示明确错误；输入新数字或使用全部清除可以开始新计算。

## 4. 交互与可访问性

- 鼠标和键盘使用同一计算状态机。键盘支持数字、十六进制 `A–F`、`+`、`-`、`*`、`/`、Return、等号和 Delete。
- Escape 关闭 Calculator 窗口；系统级 Command、Control 或 Option 组合键不被计算器截获。
- 所有按键提供可读的辅助功能名称；错误不能只用颜色表达。
- 用户可见文本使用 `Localizable.xcstrings`，支持英文与简体中文。

## 5. v0.1 范围外

- 小数、科学计算、括号或表达式编辑器；
- 位宽切换、位运算和二进制/八进制显示；
- 历史记录、磁带、变量、单位换算或持久化计算会话；
- Calculator 专属全局快捷键或设置页。

## 6. 验收

1. Root Search 可按英文或中文关键词找到并打开 Calculator。
2. 输入十进制 `255` 时同时显示十六进制 `FF`；输入十六进制 `FF` 时同时显示十进制 `255`。
3. 负数按 64 位补码显示，除零和溢出具有明确错误。
4. 鼠标和键盘可完成同一组核心运算，关闭后可由 Command 再次打开。
