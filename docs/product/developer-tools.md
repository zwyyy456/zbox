# Developer Tools 产品约定

> 权威性：Normative Product Contract
> 加载方式：涉及开发者工具入口、文本编辑、转换语义或会话生命周期时读取
> 状态：Active

## 入口与会话

Developer Tools 是随主 App 静态编译的本地工具插件，始终可用，无启用开关、独立设置页、后台监听或网络依赖。

- Root Search 提供 `developer-tools.open` 以及 `.json`、`.timestamp`、`.uuid`、`.url`、`.base64` 五个工具入口。所有入口均可在现有 Shortcuts 中绑定快捷键，并经过统一 Command Registry。
- 共用一个可调整大小的普通窗口。指定工具命令切换工具并聚焦已有窗口；总入口沿用本次 App 运行中上次选中的工具，首次为 JSON。失去焦点不关闭。
- 侧栏切换保留窗口会话中的草稿；关闭窗口或退出 App 清除输入、结果、错误、撤销记录并取消计算。窗口位置可保存，文本和转换选项不持久化；UUID 数量与大小写只在本次 App 运行中保留。
- 不自动读取剪贴板。用户通过系统粘贴输入，普通 Command-C 复制选中文本，结果按钮写入纯文本并通知 ClipboardAccessCoordinator，避免自身结果回写被额外录入历史。
- 不记录、上传或落盘输入输出；关闭窗口不会清除用户已主动复制到系统剪贴板的结果。

## 编辑与操作

- JSON、URL、Base64 使用左右输入输出；输入为纯文本，输出只读但可选择。关闭智能引号、自动替换及拼写纠正。
- Command-Return 执行当前操作，普通 Return 输入换行。Command-Shift-C 复制完整结果；UUID 为全部结果，时间戳输入为 UTC 日期，日期输入为秒时间戳。
- 修改输入或转换选项立即清除旧结果、禁用复制，取消旧计算；只在显式执行后产生新结果。失败保留输入并显示原因。
- 提供清除、复制结果及文本工具的“将结果用作输入”。JSON 错误附行列信息和定位按钮。行列按文本字符计数，CRLF 作为一次换行。
- 文本转换输入上限为 1 MiB；JSON 嵌套最多 256 层，格式化结果最多 8 MiB。超限明确失败，不截断内容。

## JSON

- 标准 JSON 语法，顶层允许任意 JSON 值；支持格式化（两或四空格）、压缩、单独校验。
- 格式化只调整字符串之外的空白，保留字段顺序、重复键、数字原文和字符串转义。数字不转浮点，不通过字典重建内容。
- 校验仅验证语法，不保证对象键唯一或符合业务 Schema；校验成功不生成可复制的转换结果。
- 不支持注释、尾逗号、JSON5、键排序、JSONPath、树形编辑或 Schema。

## 时间戳

- 时间戳输入明确选择秒或毫秒。秒允许最多三位小数，毫秒为整数；支持负值，不接受指数、加号或超限精度。首尾空白忽略。
- 日期输入为 `YYYY-MM-DDTHH:mm:ss[.SSS]Z` 或带明确 `±HH:mm` 偏移的形式；小数可为一到三位。必须是真实日期，不接受闰秒或无时区时间。
- 全部支持年份使用公历规则，UTC 范围为 0001-01-01 至 9999-12-31，精度为毫秒；数值解析及单位换算保持整数毫秒语义。
- 同时展示秒、毫秒、UTC 和本地日期，本地日期注明时区标识与偏移；每个结果可独立复制。“当前时间”填入并转换一次当前值，不持续刷新。
- 本地时区偏移由系统时区数据库按目标日期决定；边界时刻的本地年份可能超出 UTC 年份范围。

## UUID

- Foundation UUID v4，显式生成 1～100 个，每行一个；默认小写，可切换大写。
- 切换大小写不会重新生成；支持单个复制、全部复制和清除。生成行为不自动修改剪贴板。

## URL

- 面向 URL 组件，保留 ASCII 字母、数字与 `-._~`，其余内容按 UTF-8 百分号编码。完整 URL 的结构分隔符也会被编码。
- 空格编码为 `%20`，加号编码为 `%2B`；解码时 `+` 保持字面量加号，每次只解码一层。
- 非法百分号序列或非 UTF-8 结果明确失败；不做表单编码、完整 URL 编辑或自动打开链接。

## Base64

- UTF-8 文本编码及解码，支持标准与 URL-safe 字母表。标准输出保留 `=`，URL-safe 输出省略填充。
- 标准解码要求完整填充；URL-safe 接受正确填充或省略填充。允许 ASCII 空格、Tab、CR、LF，其他非法字符、错误填充及非零填充位拒绝处理。
- URL-safe 不接受标准字母表的 `+`、`/`；标准模式不接受 `-`、`_`。非 UTF-8 二进制结果显示错误，不以替换字符显示。
- 空文本可编解码为空文本；第一版不支持文件、图片或任意二进制导出。

## 选中文本入口

`developer-tools.selection` 通过 Registry 和核心快捷键显式读取原应用的选区，打开现有工具窗口，并让用户选择 JSON、URL 或 Base64 后导入。已有非空草稿时按钮明确为“替换草稿”；取消或读取失败不修改输入。导入保持原文，转换仍需显式执行；不自动复制或替换原应用内容。窗口关闭清除待导入文本。

选区读取使用共享 SelectedTextReader，独立于 Text Lookup 启停；只读取 Accessibility 暴露的当前选区，不模拟复制、不读取剪贴板、不读取正文或来源。恢复原目标后捕获；权限缺失、安全输入、受保护文本、目标变化或超过 1 MiB 时拒绝，不截断或落盘。
