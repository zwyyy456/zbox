# Workspace 产品约定

- 权威性：Normative Product Contract
- 状态：Active

## 范围与入口

Workspace 是默认关闭的内置插件，独立于 Window Management 启停。保存应用窗口布局，通过 Settings、Root Search 和统一命令快捷键恢复。每个应用只保存一个布局模板，恢复当前普通主窗口，不恢复特定文档、标签、终端会话或 Mission Control 桌面；不关闭其它应用，不调整显示器模式，不自动触发恢复。

Settings 管理工作区。创建命令先捕获布局再打开新建表单；更新也须预览确认后覆盖。用户选择应用、布局模板窗口、名称与恢复后激活的应用。至少保留一个应用。编辑支持重命名和删除条目。工作区 UUID 是命令身份，改名保留快捷键，删除清理快捷键。

## 捕获与恢复

捕获排除 zbox、全屏、最小化、非标准或不可调整窗口。窗口标题仅用于当前选择界面，不持久化、不记录日志。保存应用标识与位置、显示器标识，以及相对显示器可用区域的矩形。

恢复先检查权限和显示器。缺失或无法唯一匹配的显示器由用户选择本次映射、跳过或取消，不修改已存布局。位置按当前可用区域比例转换。应用报告的普通主窗口优先；否则只接受唯一候选，不猜测多个窗口。应用未运行时启动并最多等待窗口 10 秒，不模拟新建文档。特殊窗口、全屏和其它 Space 的窗口不主动搬迁。

一个任务串行恢复条目；单项失败继续，权限撤销停止。重复触发不并发执行。取消仅停止后续操作，不回滚已启动应用或已移动窗口。最后仅激活成功恢复且由用户指定的应用。设置显示当前进度、取消和本次逐项结果，部分失败具有明确反馈，不保存历史。

## 权限与数据

使用共享 Accessibility 授权，普通命令不弹授权请求。权限撤销关闭插件并停止任务和快捷键；重新授权后须手动启用。退出仅停止运行，保留偏好。

布局以 Codable 数据保存在本机 UserDefaults；不上传，不保存窗口标题、内容或截图。不可解码的存储明确报错并保留原数据。

## 验证

纯布局计算、显示器匹配、序列化、命令行为与取消前不访问平台的边界使用必要单元测试；真实窗口、启动、取消、多屏、Space 和权限变化人工验证。不默认运行 UI 测试。
