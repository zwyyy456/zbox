# Screenshot 产品约定

- 权威性：Normative Product Contract
- 状态：Active
- 适用范围：Screenshot 内置插件 v0.1

## 入口与截图

随主 App 静态编译，默认关闭。截图命令 `screenshot.area`、`screenshot.window`、`screenshot.screen`、`screenshot.scrolling` 经 Command Registry 执行，可在 Shortcuts 设置直接快捷键；关闭时命令打开插件设置，不捕获屏幕。

只在用户执行截图命令时捕获。区域限定在一个显示器内，窗口模式选择可见窗口，屏幕模式捕获触发时鼠标所在显示器；不拼接多个显示器。所有模式均不按应用归属、窗口层级或桌面类别主动过滤系统允许捕获的内容；zento 的设置、贴图、编辑器、预览及截图工具界面同样可被捕获。启动截图不主动隐藏现有编辑器或关闭预览、OCR 窗口。区域／屏幕截图捕获当时可见的合成画面，窗口截图不带阴影、不包含指针。选区基于实时画面，截图在确认选区后执行；不承诺冻结动态内容。

窗口选择使用相机光标，以半透明色层和边框标记当前命中的窗口；单击确认捕获。窗口候选来自开始选择时系统提供的屏幕窗口，保留其前后顺序，不限制普通窗口层级；之后新建的本次选择层不在这份候选快照中。区域截图在选区层仍可见时捕获，完成后才结束选择层；滚动截图保留选择层至会话完成，并允许鼠标穿透以滚动内容。区域选择继续使用十字光标。

Escape 或右键取消选区，不保存、复制或上传。已有截图窗口在选择期间保持显示，取消不切换或重新打开它们；成功的新截图替换该会话。设置显示当前进程的屏幕录制授权状态，进入设置及应用重新激活时刷新；未授权时提供调用系统权限 API 的“请求授权”，并保留系统设置入口供拒绝后手动开启。请求授权本身不截图，不申请 Accessibility。权限撤销、目标窗口或显示器变化时显示失败，不绕过系统限制。

## 编辑与输出

截图后默认在截图所在显示器显示不抢焦点的小预览，可在设置中改为直接打开编辑器。小预览按原图比例缩放至最大 360 × 280 点，图片下方仅保留 44 点图标操作栏；极窄图片的窗口为操作栏保留 200 点最小宽度。编辑、复制、保存、贴图和识别文字均直接显示，附带工具提示和辅助功能名称；打开编辑器沿用同一截图，不重新捕获，并关闭小预览。小预览中的复制、保存和贴图成功后关闭并释放原会话；取消或失败时保留。编辑器是独立可调整窗口，每张新截图首次打开时按图片比例、屏幕缩放及当前屏幕可用区域适配窗口和初始缩放，保留工具栏最小宽度。底部仅有一条 28 点状态栏，包含像素尺寸、缩放及即时提示；无提示时不保留额外空行。画布可缩放和滚动。支持裁剪、箭头、矩形、文字、马赛克、实色遮挡以及撤销／重做。马赛克按固定像素块处理原截图，矢量标注与实色遮挡位于其上层；预览、导出、OCR 与贴图共用此合成顺序。原图和标注分别保留在会话内；关闭窗口或停用释放会话，没有截图历史数据库。

编辑器使用窗口原生工具栏集中保存、贴图、编辑工具、撤销重做、OCR 和完成操作；复制、保存和贴图直接显示为图标按钮；更多菜单仅放格式和手动上传。文字工具使用 T 图标，点击画布位置直接输入，回车确认、Escape 放弃；点击已有文字可修改，修改支持撤销。OCR 从工具栏进入并可返回图片，不常驻图片／文字切换条。复制和保存成功使用固定状态位置的短暂反馈，失败保留提示。

复制始终输出 PNG；保存和上传使用所选 PNG／JPEG 格式。预览和导出共用合成规则，输出仅包含裁剪区域与合成后的像素，不附带原图或可撤销标注数据。自动复制和自动保存默认关闭，可分别启用；自动保存须先选定文件夹，使用唯一文件名，不覆盖既有文件。两项只处理普通截图和滚动截图完成时的原图，后续编辑需要手动导出；快捷 OCR 和快捷贴图不触发自动输出。PNG／JPEG 与 JPEG 质量在设置中选择。自动复制等待期间若剪贴板已变化则保留新内容。保存失败保留截图并提示，不更换目录；未开启自动保存且未手动保存的图片不落盘。

自动上传默认关闭，此时“完成并复制”复制最终图片。启用自动上传后按钮为“完成并上传”，该动作生成并上传最终合成图；选择区域、添加标注和保存图片本身不触发上传。任意时候可显式选择“上传”。不包含自动滚动、测量、录屏或自定义脚本。

完成并复制成功后关闭编辑器；工具栏的复制图片保留编辑会话。完成并上传在上传成功且链接已复制后关闭；失败或剪贴板变化导致链接未复制时保留窗口。贴图左上角常驻关闭和更多控件，关闭在左、更多在右，其余操作由原生菜单提供；拖动图片区域移动浮窗，按钮与菜单不触发拖动。

## 图床

配置默认图床后，小预览显示独立上传图标；未选择默认图床时隐藏。点击复用手动上传流程，显示进度并允许取消，成功后按剪贴板变化保护规则复制链接，并提供显式复制链接入口。上传成功且链接复制后关闭小预览；取消、失败或剪贴板变化导致链接未复制时保留，显式复制链接成功后关闭。上传按钮出现时，极窄图片的小预览最小宽度为 216 点。

允许保存多个配置，并显式选择默认图床。删除默认配置后清除选择并关闭自动上传，不自动换用其它目标。上传期间固定使用启动时的目标、图片格式和导出内容。凭据与普通配置分开保存。

| 图床 | 上传协议 | 配置要点 |
| --- | --- | --- |
| Cloudflare R2 | S3 SigV4，Region 为 auto | 账户上传 Endpoint、Bucket、Access Key／Secret Key、可选临时 Token、公开访问地址 |
| Amazon S3 | S3 SigV4 | Bucket、Region、密钥、可选临时 Token、公开访问地址；普通桶使用区域 Endpoint 的路径式寻址 |
| 阿里云 OSS | OSS V4 | Bucket、Region（如 cn-hangzhou）、密钥、可选 STS Token、公开访问地址 |
| 腾讯云 COS | COS SHA1 签名 | Bucket（含 APPID）、Region、SecretId／SecretKey、可选临时 Token、公开访问地址 |
| 七牛云 | 上传凭证与表单直传 | Bucket、对应区域的 HTTPS 上传 Endpoint、AK／SK、公开访问地址 |
| 又拍云 | REST PUT 与 HMAC-SHA1 签名 | 服务名、操作员及密码、公开访问地址 |
| SM.MS / S.EE | S.EE 当前文件上传接口 | S.EE API Key；链接由响应提供，旧 SM.MS 上传端点不使用 |

对象存储上传地址与公开访问地址独立。访问地址应包含桶或 CDN 所需的固定前缀，不包含本次对象路径；zento 添加配置的文件前缀与随机文件名，不以应用名、窗口标题或截图内容命名。zento 不调整桶 ACL，不自动生成私有桶的临时访问链接；上传成功不代表链接已经公开可访问。SM.MS / S.EE 按服务 API 默认规则上传并返回链接。

“上传测试图片”仅发送固定生成图片，仍会在所选服务生成远端文件；不捕获屏幕。API 和签名资料的核对记录见 `../archive/screenshot/implementation.md`。

## 上传任务与隐私

只发送当前截图会话的最终导出图或用户明确触发的测试图片；不读取剪贴板历史、不监听目录、不后台采集屏幕。请求仅使用 HTTPS，保留系统 TLS 校验，拒绝重定向转发签名或令牌。凭据保存在本机 Keychain，不进入 UserDefaults、日志或错误提示；错误提示不输出响应正文、完整授权头和签名。

上传成功提供 URL／Markdown 复制。自动复制前核对上传开始时的 changeCount：等待期间剪贴板变化则保留用户的新内容，提供显式“复制链接”动作。图片与链接回写使用 currentHostOnly。截图手动复制和自动复制的图片按 Clipboard History 的采集规则记录；上传链接通过 ClipboardAccessCoordinator 排除。

失败或取消后保留当前会话的最后一次导出快照，用户可显式重试；重试使用原图床和原对象名并重新签名，不把后续编辑混入旧请求。配置已改变时要求重新发起上传。没有自动重试、断点续传、离线队列或启动重传；服务不保证幂等时，手动重试仍可能留下重复远端文件。

停用、关闭编辑器或开始新截图取消旧上传并丢弃重试快照。旧任务的进度、失败和成功结果不得更新当前会话、回写剪贴板或重新打开窗口。取消不等于远端删除：服务可能已经收到图片。上传期间禁用画布编辑及重复提交；不提供远端删除功能。

## 验证

自动测试使用生成图、虚构凭据、公开签名样例、模拟响应和隔离剪贴板，覆盖坐标变换、裁剪／遮挡导出、签名、响应校验和剪贴板变化保护。真实授权、多屏与 Space、窗口选择、Keychain 提示以及七种图床的实际上传按 `../release-readiness.md` 人工验收。

## 文字识别

编辑器通过 Apple Vision 在本地识别最终合成图，裁剪和遮挡先于识别生效。结果可编辑、复制，保留识别行顺序；默认自动语言及纠错，允许选择系统支持的语言或关闭纠错。编辑、撤销、切换选项、新截图或关闭会话会清除结果并取消旧请求；旧任务不得回写。识别不自动复制、上传或保存，不承诺表格和多栏排版还原。

小预览的识别文字按钮直接识别当前截图，打开独立文字窗口进行识别后关闭小预览，不自动复制。

`screenshot.ocr` 提供可绑定快捷键的区域文字识别入口；完成框选后自动识别，在独立文字窗口显示，不替换原截图编辑文档。取消框选保持原有窗口；关闭文字窗口取消识别并释放结果。

## 贴图

编辑器的贴图保存最终合成图快照，后续编辑不改变贴图。浮动 NSPanel 支持拖动、等比例缩放、透明度、原像素 PNG 复制/保存和 OCR；普通窗口失焦后保持显示，允许跨 Space 和全屏辅助显示，特殊全屏/系统安全界面不作覆盖承诺。关闭编辑器不关闭贴图；停用插件或退出关闭全部，不保存历史。最多 10 张、合计 256 MiB 解码图像，超限提示，不自动删除旧图。不提供鼠标穿透。

`screenshot.pin.capture` 框选后直接贴图；`.clipboard` 只在用户触发时读取一张 PNG/TIFF 图片，拒绝私密/临时标记、文件 URL、多项、超过 32 MiB 编码数据或 6400 万像素的图像；图像解码应用方向信息。`.toggle` 切换全部可见性，`.close` 关闭全部。快捷贴图不替换编辑文档，屏幕捕获不排除 zento 自身窗口。

## 滚动截图

`screenshot.scrolling` 框选单屏区域后开始采集，由用户缓慢向下滚动，浮动面板实时预览已确认的拼接结果。确认选区后，选择层只保留区域外的遮罩，停止绘制白色描边和操作提示；滚动边框绘制在捕获区域外且没有窗口阴影，不拦截鼠标。预览面板可以拖开。固定导航栏、页脚应排除在选区外。不发送滚动事件，不新增 Accessibility 权限。

仅追加通过位移和重叠像素校验的新条带。静止画面不重复追加；暂时无法确认重叠时保留最后可靠参考帧，继续采集最多 500 ms，后续帧必须与该参考重新确认重叠才能追加。持续无法对齐时暂停采集，保留已捕获内容。用户可回滚到最后预览位置后重试、直接完成当前结果或取消；不得跨过未经确认的内容缺口拼接。采集目标间隔为 100 ms，与拼接独立执行；最多缓存两张待处理帧，积压超限时明确暂停。固定栏、动画、懒加载、重复内容不承诺自动消除或还原。

新增条带复制为独立像素存储，预览限制为 240 × 720 像素范围，完成时才生成原尺寸长图。单帧最多 1600 万像素；结果最多 3200 万像素、60000 行、512 个条带，任一上限到达后停止追加并允许完成当前结果。3200 万像素对应约 122 MiB 的 RGBA 条带数据，不是进程峰值内存上限；最终合成、采集和图像配准另需内存。不写临时截图文件。

“完成”停止采集并等待正在处理的帧结束，将结果按截图后显示设置送入小预览或编辑器，复用编辑、OCR、贴图、复制和上传。“取消”、新截图或停用取消采集并释放会话，不保存或上传；取消后恢复原编辑文档。屏幕变化或权限失效停止采集，已确认内容仍可完成。完成前不自动上传。
