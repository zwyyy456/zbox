# Application Menu 产品约定

默认关闭的内置插件，搜索并执行唤起 zbox 前应用通过 Accessibility 暴露的菜单项。入口及直接快捷键经过 Registry，未启用时打开独立设置页。

面板显示目标应用、搜索框、菜单标题、完整父路径、可读取的字符快捷键、勾选与可用状态。多词同时匹配标题和路径，维持原菜单顺序。禁用项可见但不能执行；纯容器和分隔线不作为动作。每次打开重读，关闭释放 AX 对象，不保存或记录菜单内容。

读取设置单次 AX 通信超时，并限制总读取时间与节点数量；超限明确失败，不展示冒充完整结果的截断列表。不模拟鼠标展开私有菜单，不承诺覆盖未暴露的动态菜单或应用内部命令。

执行前检查目标应用、当前前台与菜单有效性，重新读取可用状态后执行 AXPress；目标消失或用户已切换到其它应用时拒绝。权限缺失提供设置入口，授权由用户主动请求；权限撤销停用插件并关闭会话，重新授权后需重新启用。停用保留快捷键配置，停止注册。

真实应用、Space、动态菜单与权限撤销通过人工验证，不默认运行 UI 测试。
