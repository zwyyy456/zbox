# Quicklinks 产品约定

- 权威性：Normative Product Contract
- 状态：Active
- 适用范围：Quicklinks 内置插件 v0.1

## 入口与管理

默认关闭，独立设置页管理名称、类型、目标、空格分隔关键词及可选参数提示。支持固定网址、文件／文件夹、App URL Scheme，以及含 `{query}` 的 HTTP(S) 网址。文件位置通过系统选择器填写；移动后需重新选择，不跟踪文件迁移。

`quicklinks.manage` 始终可搜索并打开设置。启用时每条入口按稳定 UUID 注册命令；根搜索与直接快捷键均经过 Registry。重命名不改变快捷键，删除同时清理快捷键；停用保留数据，但移除条目命令与实际快捷键注册。

## 执行

固定入口由系统默认处理程序打开。无效地址、缺失文件或系统拒绝打开显示明确错误，不执行脚本，不获取网页预览。

带参数入口采用两步交互：先执行入口，再在临时面板输入参数并回车打开。面板显示名称、目标域名和输入提示，自动聚焦，Escape 取消；空白输入不可执行。参数仅在本次面板会话中保留；关闭、停用、编辑或删除入口后清理。

只支持 `{query}`，允许重复出现。参数按单个值进行百分号编码；占位符只允许在 HTTP(S) 路径和查询参数值，不可出现在主机、用户信息、参数名或 fragment。固定深层链接不支持参数；拒绝 javascript、data 和由网址字段输入的 file scheme。文件通过文件类型单独管理。

## 存储与范围

使用 Application Support/zbox/quicklinks.json 本地原子保存；保存失败不更新内存列表，读取失败保留文件并禁止覆盖。UserDefaults 只保存启用偏好。地址及用户输入不进入日志；输入仅在用户执行时交给目标浏览器或应用，zbox 不上传或建立搜索历史。

首版不含根搜索单行参数语法、多参数表单、脚本、书签同步或导入导出。

## 选中文本

`quicklinks.selection` 显式读取原应用选区，在原参数面板中选择已有的带参数链接并预填参数；用户确认后才打开网址。没有参数链接时提示先配置，不捕获内容。复用共享选区读取的权限、目标与 1 MiB 上限；不依赖 Text Lookup、不读取剪贴板。关闭或停用清除选区文本，条目编辑／删除沿用现有面板清理。
