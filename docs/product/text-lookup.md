- 状态：Active

- 适用范围：Text Lookup 内置独立扩展 v0.1
- 职责：定义 Text Lookup 的当前产品范围、用户行为与验收边界；实现 ownership、平台 seam 和并发边界见 `../../engineering-guidelines.md`

## 产品定位

Text Lookup 是随主 App 静态编译、拥有独立启停生命周期、状态和设置边界的当前内置独立扩展。它不是 macOS App Extension 或动态插件系统，也不建立第三方 Runtime、SDK 或插件市场。

## 用户行为与边界

- 双击取词、划动取词和光标取词分别启停及配置快捷键。双击支持直接双击，或按住快捷键再双击；划动支持选中后立即查询，或选中后按快捷键查询；光标取词在鼠标指向文字时按住快捷键 500ms 后查询，一次按住只触发一次，提前松开取消。
- 快捷键可录制单独修饰键或带修饰键的组合键；录制期间暂停取词。启用的组合键由取词监听拦截，避免输入字符覆盖来源选区；无法建立键盘监听时明确报错并保持停用。划选确认与光标取词不可配置相同快捷键；与命令快捷键冲突时拒绝更新。双击与划选确认不可共用快捷键；双击是鼠标手势，可与光标共用按住条件，鼠标按下取消待触发的光标查询。
- 普通点击不读取旧选区，只有双击或实际拖动才触发自动取词。本应用普通窗口与其他应用使用相同触发规则；取词浮窗自身的鼠标操作不触发自动查询，显式快捷键仍按对应方式处理。
- 默认不排除任何应用。升级时移除旧版写死的 zento、FlashDict 及其开发版排除项，保留其他用户排除项；之后所有排除项都可添加和删除。安全输入和用户排除的应用停止整个读取流程，不能转向双击、复制或 OCR；所有已启用方式均无法读取的文本表面明确提示失败。
- Accessibility 取词按控件实际提供的字符范围或文本标记读取；命中叶节点时允许向有限层级的父文本容器查询。兼容采集前的安全检查沿父链走到应用根节点，不用固定层数截断；遇到安全文本、无法确认的父链或循环则停止。字符总数、选区范围和原句不是已读到词条的必需条件；静态文本仅按实际字符边界定位；浏览器将同段内容拆为文本与链接节点时，在最近段落容器内有界地重建原句，保留引文前的主句和完整引文。不按控件宽度猜词，不读取整页文档。
- 光标取词先通过 Accessibility 定位；“允许模拟双击”开启时，失败时可在已识别的文本控件上模拟无修饰键双击。按钮、链接等操作控件不双击。仅接受同一目标文本控件上新产生且覆盖点击位置的选区，无法确认时不使用旧选区；不通过额外点击恢复原选区。模拟事件不再次触发取词监听。
- “使用本地 OCR”开启时，光标取词在 AX／双击读取失败时识别鼠标附近的词；已有词语但缺少原句时，划选和光标取词均可异步补充上下文，不替换已取得的词语、不重启词典查询。划选读取失败不改为查询鼠标下的其他词。
- 模拟双击、本地 OCR 和兼容复制默认开启且独立保存；未设置过的选项采用默认值，保留用户明确关闭的选择。兼容复制仅在该选项开启时读取真实选区或已验证的双击新选区。缺少屏幕录制权限时仍可使用 AX 与双击取词，OCR 给出设置入口，不在后台弹出授权请求。
- OCR 通过 ScreenCaptureKit 静默截取目标窗口在所在屏幕上的可见宽度、以词语中心上下各扩展 160 点的横向区域，再裁剪到窗口与屏幕边界；无法确定来源窗口时不扩大为整屏读取；在查词浮窗出现前截取，使用 Apple Vision 本地识别。截图仅在本次识别期间保留在内存，不写文件、不上传。OCR 必须通过文字边界命中目标位置，补原句时还需匹配已有词语；先按目标词定位正文列，再合并相邻行并通过 NaturalLanguage 的 NLTokenizer 按句切分；不再限制为上下各三行。接触截取边缘或无法确认完整句子时标明“上下文片段”。
- 新取词、关闭会话、停止插件、录制快捷键或真实鼠标点击会取消进行中的读取；过期 OCR／翻译结果不能覆盖新会话，词典内切换词条后不再应用旧上下文。双击与屏幕读取前复核前台应用、排除项和安全输入。
- 设置页提供“内置系统词典”和“FlashDict 窗口”两种来源。新安装默认内置；升级时已有 Text Lookup 配置保持 FlashDict 来源。选择持久化，运行状态和查询失败不自动改变来源。
- 内置来源由 zento 打开自己的窗口，查询 macOS“词典”中已下载、启用的系统词典，沿用启用顺序，以原始 HTML 富文本展示，并加载所属词典的样式、字体、图片和发音资源。不需要安装或启动 FlashDict；不提供任何建卡入口。系统词典下载和启用交给系统“词典”应用，变更后重新启动 zento 读取列表。
- FlashDict 来源直接调用其原句小窗口，传递词语、原句、来源 URL 和尽力获取的屏幕锚点。zento 不接收或展示 FlashDict 释义，不代理资源，不处理义项或整词建卡。翻译、词条导航、音频、建卡及额度反馈全部由 FlashDict 负责。
- FlashDict 必须已经运行，并与 zento 使用匹配的 Debug／Release 连接和协议版本。连接失败提供明确的启动／重试入口，不自动启动、轮询、重连或切换系统词典。
- 两个窗口编译复用 LookupPresentation 的窗口呈现、原句交互与整体滚动实现；各自拥有当前会话和窗口实例。一次触发只打开所选来源对应的结果窗口。取词失败和连接失败由 zento 提示。
- 标题和固定／关闭按钮保持可见；原句、翻译、释义按实际高度排列，共用一个纵向滚动区，不各自限制高度或独立滚动。窗口不主动抢走来源应用焦点；默认点击外部关闭并清理会话，固定后保持悬浮、可拖动及调整大小。新查询复用窗口并保留用户调整的位置和尺寸；固定不锁定位置，也不跨启动保存。Esc 和关闭按钮仍可关闭固定窗口；菜单、语言下载和附属对话框不视为外部点击。
- 异步 OCR 只补充匹配会话、匹配原始词语的上下文；FlashDict 已关闭或切换词条时忽略旧补充，不重新开窗、不重新查释义。zento 停用、退出或切换来源时只结束自己仍持有身份的远程窗口会话。
- 内置来源的翻译由 zento 独立配置，支持 Apple 本机翻译、用户 DeepL API 和 OpenAI 兼容 API。源语言默认自动识别，支持手动指定；源／目标语言分别保存，弹窗显示识别结果。系统语言模型缺失时先提示，用户检查语言并点击下载后才请求系统下载。远程服务仅在用户明确选择并保存后接收原句，不自动更换服务或重试其它来源。
- 远程翻译地址、模型等普通配置只保存在本机，密钥只进入 zento 自己的 Keychain，与 FlashDict 设置、凭据分离。FlashDict 来源使用 FlashDict 的翻译设置，zento 中的翻译设置只作用于内置来源。
- 捕获内容、释义和翻译只存在于本次会话，不建立取词历史，不把正文写入普通日志。OCR 图像只在内存中处理；远程翻译按用户选择发送原句，建卡仅在 FlashDict 窗口中由用户显式执行。
- Accessibility 被拒绝时提供系统设置入口；兼容复制只在该选项开启时作为单次受控操作，并避免覆盖用户随后产生的剪贴板内容。
