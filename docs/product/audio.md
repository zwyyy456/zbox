# Audio 产品约定

Audio 是默认关闭的内置插件，控制系统默认输入／输出设备。Root Search 与直接快捷键经过 Command Registry；未启用时命令打开 Audio 设置。

提供音频面板、输入／输出设备搜索、输出音量增减（每次 5 个百分点）、输入／输出静音切换。音频面板以原生表单显示两类设备和可写的主音量／静音控制；没有主控制的设备显示不支持，不模拟麦克风静音。不调整系统提示音专用设备、不管理逐应用音频、不录音、不配对蓝牙设备。

设备能力以 Core Audio 实际属性为准。执行前重新读取目标，执行后回读实际状态；设备变化刷新列表，不自动执行备用设备策略。启用时监听设备、默认设备及当前设备控制变化，停用移除监听、关闭面板、保留系统当前设置。设备信息只保留在内存。

设置只保存启用状态；快捷键由核心管理。界面支持键盘操作、英文和简体中文。真实设备切换、热插拔和设备属性支持情况通过人工验证。
