# 可安装扩展

外部扩展是用户明确信任的本地程序，通过 Command Registry 从搜索或直接快捷键触发。独立进程隔离故障，不提供文件或网络沙箱。个人自动化及 Apple 快捷指令保持原行为；内置功能继续静态编译。

## 管理

设置中的“扩展”管理本地目录或 `.zbox-extension` ZIP 包的导入、独立启停、手动升级与卸载。安装前展示来源、版本、命令与能力；安装不执行代码。解释器或环境缺失时明确报错，不自动安装依赖。

同一扩展 ID 的替换由用户明确确认，新增能力重新授权。升级保留稳定命令的快捷键及设置；删除的命令清理快捷键。禁用保留配置，立即阻止新调用并结束现有会话。卸载允许选择保留或删除数据及凭据。运行中升级或卸载需明确停止会话。安装失败保留原有效版本；不自动回滚插件运行后的副作用。

## 执行

每包一个活动会话，重复触发聚焦现有会话，不同包相互独立。task 命令使用 argv 参数、有限超时和文本结果，关闭窗口不取消；interactive 命令使用宿主渲染的列表、详情、表单和操作，关闭窗口结束会话。会话不依附 Root Search 启动任务。

停止、禁用和退出使会话先失效，再取消宿主任务、终止进程组并回收。已发生的副作用不能撤销，主动脱离进程组的守护进程不受支持。退出 zbox 等待清理。进程崩溃或协议错误明确结束会话，不自动重试命令。

## 界面与能力

Root Search 只发现命令，不把普通搜索词发送给扩展。扩展窗口支持查询、列表、纯文本详情、表单、操作与状态反馈；不嵌入第三方 SwiftUI View 或执行 HTML。完整界面快照使用稳定字段 ID 保留输入与焦点，旧事件结果不得覆盖新状态。

选区、剪贴板、粘贴由用户命令或操作显式触发。选区指原目标应用在读取时的当前选区，不预先捕获。宿主检查声明、用户授权、会话身份和系统权限。普通设置、JSON 数据与 Keychain 凭据按包命名；此命名不构成操作系统隔离。内容不进入普通日志。

首版不提供市场、自动更新、安装钩子、后台任务、窗口/截图 API 或强隔离执行环境。
