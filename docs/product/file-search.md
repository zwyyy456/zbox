# File Search 产品约定

- 权威性：Normative Product Contract
- 状态：Active
- 适用范围：File Search 内置插件 v0.1

## 范围与生命周期

默认关闭。`filesearch.open` 始终可搜索，未启用时打开设置；启用后从 Registry 打开独立文件搜索面板，支持一个可录制全局快捷键。文件结果不注册为独立 Command，也不混入 Root Search。

用户明确选择本机或本地外接磁盘目录；提供桌面、文稿、下载快捷添加。不自动扫描全盘、不接入网络卷；重叠范围拒绝添加。根目录记录卷 UUID 和目录文件 ID，同名替换磁盘／目录不能直接沿用原索引，需要移除后重新选择。

每个搜索目录可开启隐藏文件并排除明确子目录。默认跳过隐藏文件；不跟随目录符号链接，不进入应用包内部。zbox 的 Application Support 数据目录始终排除，避免索引自己的数据并反复触发更新。首版不解释 .gitignore。

停用停止查询、扫描和监听并保留配置、索引；关闭面板仅取消查询与预览。移除搜索目录异步清理对应索引记录，不删除磁盘文件。清除索引保留配置及文件；插件启用时重新建库，关闭时保持空库。

## 索引

使用独立本地 mmap 二进制索引保存文件和目录名称、相对路径、类型、扩展名（由名称派生）、普通文件大小、修改时间及根目录事件位置。不开启 CloudKit，不建立正文、查询或打开历史；文件名、路径和查询不进入日志。

每个搜索根目录保存独立的只读快照，名称去重并建立字符位图、目录表及文件映射，完整路径由目录与原始名称组合，不为每条记录重复保存目录前缀。运行中变化先进入分块的内存增量区，查询合并基础快照与增量；首次完整扫描后保存；运行中按变更数量和距上次保存的时间批量合并。文件格式版本不支持、结构损坏时重新扫描。用户的目录、排除规则和快捷键配置保留。

快照与对应事件位置一起原子替换；未持久化的变化在重启后从磁盘快照的事件位置重新核对。后台合并期间的新变更继续保留；扫描失败不推进持久化事件位置。

启用、启动或唤醒时，校验搜索目录身份、收录规则和卷的 FSEvents 日志 UUID。快照与这些条件一致且事件位置有效时，从保存的位置建立监听，等待历史事件发送完成，仅核对期间发生变化的目录；不重新遍历整个搜索范围。首次建库、索引损坏、配置或事件日志变化、事件位置失效及用户手动重扫时完整扫描。

普通文件事件只核对父目录的直接子项，保留未访问子目录中的记录；目录新增、移除或重命名核对对应子树。事件丢失、根目录变化及系统要求递归扫描时完整核对搜索根目录。完整扫描先建立监听，并处理扫描期间积累的变化。事件位置只有在对应核对完成后才推进；历史完成通知本身不代表扫描已完成。

扫描在后台按批次更新，快照分区流式写入临时文件后原子替换，过程中可以查询已有记录。只有完整遍历成功才清理该范围内未再出现的旧记录；访问失败、取消不被解释为文件删除。状态区明确显示扫描中、不完整、离线或已就绪，首次扫描数量不是持续更新的总数。目录访问不可用时隐藏其搜索结果；挂载、卸载、唤醒后重新检查范围。

索引更新具有延迟；设置收录规则后重新扫描。索引只存元数据，云文件不在扫描时主动下载；用户打开或 Quick Look 时系统可能下载。无需 Accessibility，也不默认要求完整磁盘访问权限；受保护目录访问失败应显示不完整状态。

## 搜索与排序

普通词按不区分大小写、Unicode 归一化后的文件名包含匹配；多个词采用 AND，引号包含连续短语。支持 `ext:pdf`、`type:file`、`type:folder`、`path:project`；类型、目录范围、扩展名也能从控件选择。path 匹配完整路径，所有筛选条件取交集。引号不完整、已知筛选参数缺失或 type 无效时显示提示。正则与通配符不作特殊解释。

默认按名称完全匹配、名称前缀、名称包含依次排序；同级按归一化名称及完整路径稳定排序。可以切换名称或修改时间排序。先匹配排序再保留最佳 200 条，超出时明确提示缩小范围，不声称显示全部结果。空查询且无类型／扩展名等筛选时显示输入提示，不列出整个索引。

## 操作与界面

面板可调整大小；顶部搜索及筛选，中部结果列表，底部操作和索引状态。同名结果显示父路径；路径中间截断，名称、大小、日期各有对齐位置。

- Return：默认应用打开文件，Finder 打开目录。
- Command-Return：在 Finder 中显示项目。
- Command-C：复制文件引用；输入框存在文本选区时保留原生复制文本行为。
- Command-Shift-C：复制完整路径。
- 上下键、Control-N/P：选择结果。
- Space：仅在结果列表取得焦点时打开 Quick Look；搜索框空格正常输入。
- Escape：先关闭预览，再关闭文件搜索。

菜单提供上述操作，Quick Look 有可见按钮。中文输入法组字期间不截获执行／导航按键。自身剪贴板写入通知 ClipboardAccessCoordinator，避免历史重复记录。执行前检查目录身份和文件可访问性；过期结果显示错误并请求刷新。关闭、切换查询和改变选中项时清理旧预览。

## 首版边界

不含全文搜索、拼音／模糊匹配、复杂布尔表达式、正则、完整 gitignore、删除／移动／重命名、批量操作或跨 App 打开／保存对话框控制。不承诺 Everything 的全盘建库速度或固定规模下的响应时间。

## Finder 选中文件

`filesearch.finder-selection` 通过 Registry 与核心快捷键提供“操作 Finder 选中文件”入口，复用本插件的打开、Finder 显示、Quick Look、复制文件和路径操作。仅在用户明确执行且原应用为 Finder 时读取一个本地文件／文件夹；多选、无选区、非本地卷、目标切换、权限拒绝或文件失效均明确失败。

Finder 选区由静态 AppleScript 读取，系统按需请求自动化权限。Info.plist 明确用途，Hardened Runtime 启用 Apple Events entitlement；不要求为此启用 Text Lookup 或授予辅助功能权限。NSAppleScript 留在 Main Actor，Apple event 使用有限超时。不执行用户拼接脚本，不读取文件正文。

选区进入独立临时操作表面，复用 File Search 面板及文件动作；不加入索引，不改变搜索目录范围，不保存选择历史。Escape 先关闭预览再关闭面板，停用时清理。操作前检查文件可访问性；云文件打开／预览可能由系统下载。Finder 授权、Space、选择变化及真实文件行为通过人工验证。
