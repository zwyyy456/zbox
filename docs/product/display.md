# Display 产品约定

- 权威性：Normative Product Contract
- 状态：Active

## 范围与入口

Display 是默认关闭的内置插件。Settings 展示显示器信息、逻辑尺寸、渲染像素尺寸、HiDPI 与当前刷新率，管理模式和命名预设；搜索及快捷键通过 Command Registry 执行预设。与 Workspace 独立启停，不自动串联。首版不管理亮度、HDR、排列、镜像或虚拟屏幕。

## 模式与预设

只展示 CoreGraphics 报告可用于桌面的模式，刷新率为零时标为系统管理，不虚构固定刷新率。逻辑尺寸和渲染尺寸不等同于物理面板原生分辨率。

每次切换先检查显示器身份与模式是否精确可用；不替换为相似模式。预设保存显示器 UUID 与模式参数，不持久化短期 mode ID。重命名保留命令 UUID 和快捷键，删除清理快捷键。

切换暂时作用于 App 生命周期，15 秒内明确保留后才应用为持久配置。未确认、取消、关闭插件或正常退出时尝试恢复切换前模式。恢复失败明确报告，保留重试入口，不承诺进程崩溃、拔插或系统异常下总能恢复。倒计时中拒绝新切换；屏幕改变后重新检查，不能确认不再匹配的配置。

## 原生 HiDPI 扩展

使用显示器型号 Override 中的 `scale-resolutions` 请求额外的 2× 渲染模式，遵循原生配置路线。此机制不是 Apple 公开支持的配置 API；是否产生可用模式由系统、硬件与连接方式决定。安装成功只能表示文件写入，必须重启后回读可用模式验证效果。

用户在设置中明确选择外接显示器、输入物理原生分辨率并确认所请求的缩放档位，再通过系统管理员授权安装。配置按厂商/型号生效，可能影响所有同型号屏幕。默认不操作内建屏幕、不修改 EDID、不自动重启。

不覆盖已有第三方或系统配置。不关闭 SIP，不运行远程脚本。移除仅针对本插件生成且内容仍一致的配置文件，保留其它文件。普通模式管理不需要 Accessibility、录屏或管理员权限。

## 验证

模式匹配、临时切换/确认/失败恢复、配置序列化和特权命令输入边界使用必要单元测试。真实切换、黑屏倒计时、刷新率、多显示器、管理员授权、重启后新增模式及撤销需要人工系统验证。不默认运行 UI 测试。
