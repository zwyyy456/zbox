# Snippets 产品约定

- 权威性：Normative Product Contract
- 状态：Active
- 适用范围：Snippets 内置插件 v0.1

## 入口与管理

默认关闭。设置页管理名称、关键词、可选分组和纯文本正文；保留正文空白及换行。片段存储在 Application Support/zbox/snippets.json，本地原子保存，不上传、不使用 CloudKit、不宣称加密。写入成功后更新列表；损坏文件保留并禁止覆盖。内容不进入日志或 UserDefaults。

`snippets.open` 始终可搜索；未启用时打开设置，启用后打开临时面板。面板支持名称、关键词、正文搜索及分组筛选，使用固定存储顺序；列表与预览左右排列。上下键、Control-N/P 选择，Return 粘贴、Command-Return 复制、Escape 关闭；输入法组字期间不截获这些导航／执行按键。

启用时每条片段按 UUID 注册根搜索命令和可录制快捷键；根搜索只匹配名称与关键词，不展示正文，执行后直接尝试粘贴。改名保留快捷键，删除清理快捷键；关闭插件移除条目命令并停止全部片段快捷键，保留数据。

## 变量

- `{{date}}`：执行时的本地公历日期，格式 yyyy-MM-dd。
- `{{time}}`：同一执行时刻的本地时间，格式 HH:mm。
- `{{clipboard}}`：本次执行读取的剪贴板纯文本；重复变量共用一次读取。

编辑器提供插入变量菜单，插入到光标或替换所选文本。普通预览显示模板，不读取剪贴板。只有复制／粘贴时才展开，展开结果不递归解析。`\{{date}}` 输出字面量 `{{date}}`；未知占位符原样保留。

剪贴板变量尊重系统访问权限；无纯文本、文件列表、超过 1 MiB、已知私密／临时标记或读取时内容变化均明确失败，不输出部分展开结果、不改写剪贴板。标记过滤与 Clipboard History 使用同一标记集合，不保证识别所有敏感内容。

## 粘贴与生命周期

与 Clipboard History 共享平台粘贴操作和 ClipboardAccessCoordinator，但不依赖该插件启用。记录唤起前的目标应用，执行时先展开模板，再检查激活目标及权限，最后写入并发送 Command-V。原目标退出、前台应用变为其它应用时拒绝粘贴。缺少 Accessibility 时提供仅复制、请求权限与打开系统设置入口，普通执行不自动请求授权。

自身写入通知协调对象，避免历史重复采集；不定时恢复旧剪贴板。发送按键不代表目标应用已成功插入。重新唤起、关闭、停用、编辑和删除会取消待处理粘贴并清理会话，取消后旧结果不得重开面板。

首版不含缩写自动展开、富文本、脚本、光标定位、同步或导入导出。
