# Script Commands

Script Commands 是静态编译的内置插件，默认关闭。用户添加本地脚本后，命令通过统一 Command Registry 出现在搜索和快捷键设置中。插件不扫描或自动执行目录中的文件。

配置包括名称、关键词、脚本路径、解释器、工作目录、固定参数、运行时参数和 1–3600 秒超时。解释器为空时直接执行脚本；默认使用 `/bin/zsh -f`。固定参数逐行填写，运行时参数按配置顺序追加，每项独立传入 argv，不拼接成 shell 命令。工作目录默认脚本所在目录。

配置保存在 Application Support/zbox/script-commands.json，使用稳定 UUID 作为命令身份。损坏的配置保留原文件并显示错误，不覆盖为空列表。参数输入和运行结果不持久化。

脚本以当前用户权限运行，可以访问文件和网络。设置页明确说明此权限；用户自行维护脚本内容和解释器。插件不请求管理员权限，不提供交互式终端。
