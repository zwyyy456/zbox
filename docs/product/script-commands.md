# 自动化（Script Commands）

自动化由原 Script Commands 内置插件提供，默认关闭，支持本地脚本与用户选定的 Apple 快捷指令。原脚本命令 ID、配置路径、UUID 和快捷键不变。以下脚本规则只适用于本地脚本。用户添加本地脚本后，命令通过统一 Command Registry 出现在搜索和快捷键设置中。插件不扫描或自动执行目录中的文件。

配置包括名称、关键词、脚本路径、解释器、工作目录、固定参数、运行时参数和 1–3600 秒超时。解释器为空时直接执行脚本；默认使用 `/bin/zsh -f`。固定参数逐行填写，运行时参数按配置顺序追加，每项独立传入 argv，不拼接成 shell 命令。工作目录默认脚本所在目录。

配置保存在 Application Support/zbox/script-commands.json，使用稳定 UUID 作为命令身份。损坏的配置保留原文件并显示错误，不覆盖为空列表。参数输入和运行结果不持久化。

脚本以当前用户权限运行，可以访问文件和网络。设置页明确说明此权限；用户自行维护脚本内容和解释器。插件不请求管理员权限，不提供交互式终端。

## 执行与结果

没有运行时参数的命令立即运行；有参数时先显示输入表单，点击“运行”或按 Command-Return 执行。一次只运行一个脚本，再次触发脚本命令聚焦正在运行的窗口。关闭结果窗口不终止任务；“停止”、禁用插件和退出 zbox 会取消任务，退出会等待清理完成。

标准输入接 `/dev/null`，标准输出和错误输出分别显示。每路最多保留 1 MiB，超出后显示截断提示并继续排空管道。结果显示退出码、终止信号、取消或超时；复制需主动点击，清除和退出后不保留运行记录。

每次运行拥有独立进程组。取消或超时先发送 SIGTERM，最多等待 2 秒后 SIGKILL 并回收进程。脚本正常退出也清理其进程组中的后台作业。主动脱离进程组的守护进程不在支持范围内；此功能用于有限时长的非交互任务。

环境只传入 HOME、USER、TMPDIR、LANG=en_US.UTF-8，以及 PATH=/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin。默认 zsh 使用 `-f`，bash 使用 `--noprofile --norc`，不加载交互配置；系统强制的 shell 初始化文件仍由解释器决定。依赖其他环境的脚本应自行设置，不从 zbox 继承凭据。

## Apple 快捷指令

在设置中主动读取系统快捷指令列表，用户选择后才加入 zbox。以系统标识符绑定，显示名和关键词由 zbox 管理；运行时确认标识符仍存在，系统改名不改变绑定。列表只在添加、刷新、运行前及打开编辑器时读取，不建立后台扫描或执行历史。同名条目显示短标识以供区分；打开编辑器按标识符查出当前名称，同名时拒绝猜测，提示在系统 App 中选择。

配置使用同一 JSON 文件中的可选 shortcut 字段，旧条目无该字段仍按原脚本解释，不重建条目。输入支持无输入或用户手动提供不超过 1 MiB 的 UTF-8 文本。文本通过仅当前用户可访问的临时目录交给系统 CLI，等待结束后清理；不自动读取选区或剪贴板。快捷指令本身可以按其动作保存内容或访问网络，权限及交互提示由系统处理。

使用 /usr/bin/shortcuts 和独立 argv，按标识符运行，请求纯文本输出。输出限制及运行窗口复用原实现，不提供二进制结果预览。插件内一次跟踪一个任务，重复触发聚焦正在运行的窗口。停止按钮称为“停止等待”；取消、超时、禁用和退出仅终止 zbox 管理的 CLI 进程组并清理临时输入，不能保证终止系统快捷指令服务内的动作，也不撤销已发生的副作用。
