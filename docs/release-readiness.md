## 分发

- [ ] 使用 Developer ID Application identity 构建最终 Release，确认不包含 `get-task-allow`。
- [ ] 完成公证、staple 和 Gatekeeper 验证，并复核 Hardened Runtime、非沙盒、登录项和 Accessibility 行为。
- [ ] 确认发布产物不包含签名凭据、用户数据、调试入口或正文日志。

## Text Lookup 系统闭环

- [ ] 在 TextEdit、Safari、Xcode、备忘录、VS Code 和可选中文本 PDF 上验证选区与指针路径；不支持的表面显示明确结果。
- [ ] 覆盖 Accessibility 首次拒绝、授权、撤销和恢复，以及安全输入和排除应用。
- [ ] 覆盖普通桌面、全屏、多个 Space、单显示器和外接显示器的悬浮窗口定位、焦点、Escape 与外部点击关闭。
- [ ] 在启用兼容复制时验证 Safari 等应用，并确认恢复操作不会覆盖用户并发剪贴板修改。
- [ ] 安装 Apple 英文到简体中文模型，验证成功翻译、下载授权取消、切换目标语言和旧结果抑制。
- [ ] 使用当前源码 FlashDict 和合法测试词典验证查词、CSS/图片/音频、失败状态和手动重试。
- [ ] 使用隔离测试数据验证义项级建卡、原句/source URL、成功、额度拒绝和失败结果；不得写入用户现有卡片数据。

## 记录原则

只记录实际运行的构建版本、系统环境、场景、结果和未覆盖风险。未执行或受环境限制的项目保持未完成，不推断为通过。

## Clipboard History 人工验收

- [ ] 开启后完成剪贴板首次授权、拒绝、撤销与恢复；确认启用前内容不被补录，停用后不再记录。
- [ ] 从 TextEdit、Safari 和一个跨平台 App 复制文本、链接与图片，检查搜索、预览、复制及 Return 粘贴；无 Accessibility 时仍可复制。
- [ ] 粘贴前关闭原应用或切换目标，确认不会向其它应用发送粘贴；测试 Escape、快捷键、全屏、Space 和多显示器。
- [ ] 排除应用和密码工具内容不进入历史；启用 Text Lookup 兼容复制后，临时文本和恢复内容不进入历史。
- [ ] 清空（含置顶）并重启后历史仍为空；清空不改系统剪贴板。验证图片能被目标 App 接收，实际磁盘占用与清理情况。

自动测试只使用隔离剪贴板和临时数据库；以上真实系统行为尚未由自动测试证明。

## Screenshot 人工验收

- [ ] 首次允许、拒绝、撤销和重新授权屏幕捕获；检查搜索与直接快捷键入口，未启用时只打开设置。
- [ ] 区域／窗口／当前屏幕截图覆盖 Retina、非 Retina、负坐标副屏和全屏 Space；核对窗口高亮、选区位置、Escape／右键取消、自身窗口排除以及编辑器位置。
- [ ] 裁剪、箭头、文字、遮挡、撤销／重做、缩放，分别复制 PNG、保存 PNG／JPEG；在其它应用打开，确认方向、边缘、文字和遮挡与预览一致。
- [ ] 为 R2、S3、OSS、COS、七牛、又拍云、S.EE 各配置测试账户，先执行“上传测试图片”；验证正确区域、桶名、公开域名、Keychain 保存及应用重启后读取。检查实际生成的链接可访问，失败时校正配置。
- [ ] 检查手动上传及“完成并上传”、URL／Markdown；等待期间复制其它文字，确认不会被链接覆盖。启用 Clipboard History 后确认自身图片／链接不被额外录入。
- [ ] 上传中断网、取消、关闭窗口、停用、再次截图；确认旧结果不回写、不重新打开窗口。失败后修改编辑内容，再“重试上次上传”，确认仍发送旧快照；更改图床配置后必须重新发起上传。
- [ ] 删除默认图床后自动上传关闭且不改用其它服务；清理各测试账户中生成的远端测试图片，尤其留意取消或重试可能产生的文件。

自动测试没有使用真实图床凭据，也没有执行远端上传；以上条目完成前不能据单元测试推断服务实传或系统交互通过。

## Workspace 人工验收

以下项目需在真实 macOS 会话中完成；构建和单元测试不代表通过这些系统验收。

1. **保存与更新**：启用 Workspace，排列 Xcode、Safari 和 Terminal，保存“开发”。同一应用打开两个窗口，选择布局模板；重启 zbox 后确认配置仍在。改名、更新、移除条目，检查搜索名称与快捷键保留；删除后命令和快捷键消失。
2. **恢复与限制**：打乱窗口位置，从搜索和快捷键分别恢复。关闭一个应用后恢复，检查启动和最终前台应用。最小化、隐藏、全屏及其他 Space 的窗口应跳过或明确报错；没有普通窗口的应用最多等待约 10 秒（另有系统 AX 调用耗时），不得自动新建文档。
3. **外接显示器**：保存外接屏布局，改变缩放或 Dock 位置后恢复；拔掉外接屏，分别验证本次映射、跳过和取消。原保存布局不应被覆盖。不同尺寸屏幕及应用最小尺寸限制应有真实结果反馈。
4. **中断与权限**：恢复期间重复触发、取消、关闭插件、退出 zbox，确认不再继续移动后续窗口；已完成调整保留。撤销辅助功能权限后执行命令或回到 zbox，确认插件和快捷键停用；重新授权须手动启用。
5. **界面与隔离**：中英文检查设置 Tab、长工作区名称、空状态、捕获表单、显示器选择和部分失败列表；只用键盘完成主要操作。关闭 Window Management 不应影响 Workspace，反之亦然。

## Display 人工验收

基础枚举已在当前 M1 Pro 的内建屏与两块外接屏只读检查；未执行真实模式切换、管理员写入或重启。以下仍需手动完成：

1. **模式与确认**：启用 Display，对一块外接屏切换现有 HiDPI 分辨率与可用刷新率；分别验证保留、手动恢复、15 秒超时恢复。切换不适合时不要确认，等待恢复；核对逻辑尺寸与渲染像素尺寸。
2. **预设与快捷键**：保存双屏预设，改名后快捷键保留，搜索与快捷键均打开确认界面。拔掉其中一块屏幕后应用应明确失败，不使用相近模式。删除后命令与快捷键移除。
3. **变化与中断**：倒计时中拔插屏幕、正常退出或关闭插件，检查恢复结果与失败重试入口；若恢复失败，重新连接显示器再点击恢复。睡眠后返回不应误保留过期切换。
4. **原生 HiDPI 安装**：使用无第三方 Override 的外接屏，输入旋转前物理原生尺寸，核对型号范围提示。取消管理员授权不得显示安装成功；同型号已有配置时不得覆盖。授权安装后手动重启，刷新并核对新增模式，实际选择一个验证清晰度、刷新率、唤醒与拔插。只有这一步通过，才能确认该设备的解锁效果。
5. **撤销与界面**：移除 zbox 配置、重启并确认原有模式；被其它工具修改的文件必须拒绝删除。中英文检查模式选择、长显示器名称、预设、权限及失败说明。未运行 UI 测试。

## Quicklinks 与 Snippets 人工验收

自动验证覆盖存储失败保护、URL 参数编码、模板展开与隔离剪贴板标记过滤；以下真实系统行为仍待验证：

1. **快捷入口**：分别创建网页、文件、文件夹、已安装 App 深层链接及参数网址；从搜索和快捷键执行。输入中文、空格、`&`、`#`，确认目标收到完整参数；缺失文件或无处理 App 时错误明确，Escape 不打开目标。
2. **片段输入**：在 TextEdit、Safari、Xcode 中从面板、根搜索、快捷键分别粘贴；Command-Return 仅复制。检查变量插入位置、日期／时间、重复剪贴板变量及字面量转义；普通预览不请求剪贴板读取。
3. **权限与取消**：关闭 Clipboard History 后仍能复制和粘贴；拒绝／撤销 Accessibility 后保留复制能力。粘贴前退出原应用或切换前台，确认不误粘贴；系统剪贴板拒绝及已知私密标记明确失败。停止或重新唤起后旧任务不能改写或重开面板。
4. **管理与窗口**：中英文、中文输入法、全屏、不同 Space 下检查重复唤起、输入焦点及键盘操作；重启后数据保留，改名保留快捷键，删除／停用后相关快捷键停止。开启历史后，片段自身复制不产生额外历史记录。

## File Search 人工验收

自动测试使用临时目录和独立数据库，覆盖过滤、Unicode 查询、排序截断、目录改名、包／符号链接边界、失败保留和事件位置提交；以下系统行为仍待验证：

1. **范围与权限**：添加文稿、代码目录和外接盘目录；检查重叠拒绝、隐藏文件、排除子目录、权限拒绝及恢复。首次扫描中能查询已收录记录，不完整状态不得误报就绪。
2. **持续更新**：真实 FSEvents 下新增、删除、重命名文件和整个目录，确认旧路径消失、新路径可搜；退出 zbox 后修改文件再启动，检查追赶结果。扫描中停用、重新启用及清除索引，旧任务不能恢复监听或回写界面。
3. **磁盘与查询**：外接盘拔出后隐藏其结果，重连后恢复；同名不同磁盘不能沿用索引。连续快速输入、组合 ext/type/path、同名文件、超过 200 个匹配时排序和提示正确。
4. **文件操作与窗口**：在普通桌面、全屏和不同 Space 下，检查回车打开、Finder 定位、Finder 粘贴文件、复制路径及 Quick Look。中文组字不误执行，搜索框空格不触发预览；云文件下载提示、失效文件反馈和 Escape 关闭层级正确。中英文检查设置和长路径布局。

## Developer Tools 人工验收

自动验证覆盖编解码、JSON 原文与语法、时间戳精度和日期规则；下列系统交互仍需人工验证，未运行 UI 测试：

1. **入口与窗口**：中英文搜索六个命令，绑定并触发快捷键；重复打开复用窗口、切换正确工具，失焦保持窗口。普通桌面与全屏 Space 下检查激活、缩放和 Command-W 关闭。
2. **编辑与键盘**：粘贴中文、emoji、多行 JSON 和长行，检查普通回车、中文组字、撤销、Command-Return、选区 Command-C 与 Command-Shift-C；智能引号和替换不得修改内容。点击 JSON 错误定位，确认光标和滚动位置正确。
3. **会话与取消**：转换后修改输入或选项，旧结果与复制立即失效；连续运行及关闭后重开不出现旧结果。工具切换保留草稿，关闭后重开输入与撤销记录均清空。
4. **结果与剪贴板**：检查 UUID 数量和大小写、时间戳各项复制、结果回填、清除；打开工具不自动读剪贴板。启用 Clipboard History 后，结果按钮的自身回写不额外入库。

## OCR、贴图与脚本命令人工验收

1. **OCR**：截取中英文混排文字，切换识别语言与纠错；编辑结果后复制。裁剪并遮挡部分文字后再识别，确认结果不包含被去除内容；“截图识别文字”不替换原编辑图。
2. **贴图**：编辑后贴图，再修改或关闭编辑器，贴图保持原快照；验证拖动、缩放、不透明度、复制、保存和识别。测试多显示器、全屏和 Space 切换；显示／隐藏及关闭全部应生效，停用插件后全部关闭。
3. **剪贴板贴图**：从浏览器和预览复制图片，检查方向与清晰度。首次剪贴板授权、拒绝与恢复使用真实系统验证。
4. **脚本**：启用插件，添加自己的 zsh／bash／AppleScript；带空格和中文的参数应原样收到。检查搜索和快捷键、有参数表单、双路输出、退出码及复制；关闭窗口后重新触发应回到运行任务。分别测试停止、超时、停用和退出 zbox，并确认任务不再继续执行。

构建与自动测试不代替 OCR 实际识别质量、系统窗口层级和具体脚本的权限验收。
