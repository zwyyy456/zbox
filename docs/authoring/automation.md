# 编写个人自动化

在设置 → 自动化中启用功能，选择“添加脚本”。脚本以当前用户权限运行，只添加你信任的内容。

## 第一个命令

使用仓库 `examples/extensions/hello-task/main.zsh`，名称填写“打招呼”，解释器选择 `/bin/zsh`，添加一个必填运行时参数“名字”。工作目录留空、超时使用默认值。保存后从搜索或快捷键触发，输入名字并运行。

输入 `世界; echo unexpected` 应作为一个名字原样输出，不能执行额外命令。zbox 按顺序传递独立 argv；脚本内部仍应始终引用变量，不使用 eval。

固定参数在运行时参数之前传入，每行一个。需要文件路径时使用参数，不把用户内容拼进 shell 命令。默认工作目录是脚本所在目录，可以通过 `${0:A:h}` 定位相邻资源。

## 环境与结果

zsh 使用 `-f`，bash 使用 `--noprofile --norc`，不加载用户交互配置。PATH 为 `/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin`。依赖其他环境的脚本需自行明确设置；不要把凭据写进脚本、示例或打印输出。

标准输入关闭，脚本不能使用 read 等待交互。通过运行时参数收集输入，通过 stdout 返回结果，通过 stderr 返回错误原因，使用非零退出码表示失败。每路最多保留 1 MiB；结果仅在当前运行窗口保留。

解释器留空时直接执行文件，需要可执行权限和正确的 shebang。Python 等额外解释器由用户安装和选择，zbox 不安装依赖。

## 停止与排错

关闭结果窗口不会停止脚本，使用“停止”取消。取消或超时会终止进程组，最长等待 2 秒后强制清理；普通后台子进程也会清理，主动脱离的守护进程不受支持。不要将长期后台服务包装成脚本命令。

“不可用”时检查脚本、解释器、工作目录与执行权限。命令在终端可用而在 zbox 失败时，首先检查它是否依赖交互 shell 配置、环境变量或相对路径。输出保留退出码、信号与超时信息。

Apple 快捷指令的“停止等待”只停止 zbox 管理的 CLI，不保证停止系统服务内的动作。完整产品行为见 `../product/script-commands.md`。
